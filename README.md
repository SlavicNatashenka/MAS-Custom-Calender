# MAS-Custom-Calender
Add Custom Dates or Events to the MAS Calender!◝(ᵔᗜᵔ)◜

Features:

Add & Remove Events Directly on the Calendar! (˶˃⤙˂˶)
- Title: Name your event (Eggy's Birthday, Trip to Berlin, Exam week..)
- Dates: Pick a start date (and end date for multi-day events), with year support from 1900 up to the current year.
- Repetition: Choose Does Not Repeat, Every Week, Every Month, Every Year, or a Custom.
- Category: Choose from Birthday, Holiday, Trip, Exam, Due Date, Goal, or Misc / Other.

Birthdays: Enter the name of whose birthday it is and their birth year (1900–current year) so Monika knows how old they're turning! (˶>⩊<˶)
Trips: Enter your destination! :3

Monika Reacts to Your Events
- Automatic Greetings // Checks: Monika can greet you on the day of an event, count down 1–2 days before upcoming events, and check in on how things went 1–3 days after an event ends. Moni is so nice ₍₍⚞(˶˃ ꒳ ˂˶)⚟⁾⁾

Dialogue
- "What day is it today?" Talk Topic: Go to Talk > Hey Monika > Day > What day is it today? anytime to have Monika tell you the date and react to any events happening today.

- "Can we check our calendar?" Talk Topic: Open the calendar from Talk > Hey Monika > Misc. (Added if youre in a room that doesn't have the calendar on the wall like other spacerooms.)
